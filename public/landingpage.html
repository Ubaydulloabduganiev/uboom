Made by Uba, because apparently everything needs an alternative now.

Uboom started as a personal video meeting tool. Not a billion-dollar platform. Not a productivity cult. Just a private room for talking, teaching, sharing a screen, and surviving the internet.

Built with WebRTC, Socket.IO, and a level of patience that should probably be studied by doctors.

RULE 01

No account gymnastics

You should not need a profile, password, blood sample, and childhood memory to join a call.

RULE 02

Links should work

Send the link. Open the link. Join the room. The bar is low, but somehow many apps still trip over it.

RULE 03

Keep it private-tool simple

Uboom is for quick personal use and friends. If it becomes enterprise software, delete it and start praying.

Need a room?

Create one, send it, talk. That’s the product. Stunningly, we do not need seven tabs and a dashboard for this.
